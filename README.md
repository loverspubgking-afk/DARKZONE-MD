# 🧠 RED-MIND — Uncensored AI Agent

Autonomous AI agent powered by notrack.ai (uncensored) with:
- 🔍 Web search
- 🌐 Real browser automation (Playwright)
- 🛠️ Tools (calculator, files, shell)
- 💬 Chat interface

## Run locally
```bash
pip install -r requirements.txt
playwright install chromium
uvicorn app:app --host 0.0.0.0 --port 8000
```
